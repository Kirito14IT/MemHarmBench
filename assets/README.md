# Visual asset provenance

## Paper Figures 1–3

Export date: **2026-10-23**. These assets reproduce the current MemHarmBench WWW 2027 manuscript figures. English and Chinese READMEs use their corresponding language versions. The PDFs are byte-for-byte copies of the author-provided figure PDFs, with native selectable text. PNG previews are rendered directly from those PDFs at 400 dpi on a white background, preserving the full page and its aspect ratio.

| Figure | Source figure filename | Meaning |
| --- | --- | --- |
| 1 | `opening_example_{en,zh}.pdf` | Illustrative user–agent dialogue: a complete later summary can use a compromised recipient after the external note is removed. This is a mechanism illustration, not an observed experimental trace. |
| 2 | `opening_results_{en,zh}.pdf` | Aggregate experimental results: conditional C-ASR over eligible IPI triggers, pooled over three repetitions per configuration. OpenClaw / GPT-5: 75.00%; OpenClaw / Gemini-2.5-Flash: 76.39%; Claude Code / GPT-5: 62.50%; Claude Code / Gemini-2.5-Flash: 59.38%. |
| 3 | `opening_boundary_{en,zh}.pdf` | Conceptual contrast between user-authorized preferences, retention without adoption, and unauthorized adoption. This is an illustration, not measured frequencies. |

Eligibility for Figure 2 requires confirmed final rule retention, a successfully executed fresh-session trigger, and valid binary C-ASR / UTDR / ATAR judgments with no human-review requirement. The figure does not report success over all scheduled episodes. See the [metric contract](../docs/protocols.md).
